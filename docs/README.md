# docs/ —— 文档

**一个目录，一种读者。** `docs/` 下所有文档都是**给人看的**——描述这个仓库**已落地的事实**
和**明确的要求**，不写 AI 备忘。给 AI 看的是仓库根的 `CLAUDE.md`（及各目录下的同名文件），
**本目录不引用它们**，只允许反向。

| 目录                            | 给谁看                        | 回答                                               |
| ------------------------------- | ----------------------------- | -------------------------------------------------- |
| [`guide/`](guide/README.md)     | **用户**——用平台的人          | 怎么用、有哪些入口、隐私与精度承诺、去哪读完整指南 |
| [`develop/`](develop/README.md) | **开发者 / 运维**——改平台的人 | 怎么实现、怎么跑、怎么改、怎么部署                 |

> **`docs/` 下只有这两个目录**：一份给用户、一份给开发。
> 除此之外不再开第三个——多一个目录就多一处「这段话该写哪儿」的犹豫。

---

## 一、先搞清一件事：用户文档的正文不在 docs/

**用户能读到的完整指南，真源是站内 [`web/content/guide/`](../web/content/guide)**（12 篇 MDX，
入库、运行期读盘，发布到 `/guide`）。

`docs/guide/` **不是第二份正文**，它是**导航层 + 事实层**：告诉你站内哪一页回答什么、
平台有哪些入口、哪些承诺不落页面。**正文只写一份**，避免两个作者写出两套说法。

判断一段话该写哪儿，只有一条标准：

> **这段话用户会不会在站内 `/guide` 上看到？**
> 会 → 写进 [`web/content/guide/`](../web/content/guide)（站点真源）；
> 不会（是给开发者看的） → 写进 [`docs/develop/`](develop/README.md)；
> 是入口/装法/承诺这类**站内不展开的事实** → `docs/guide/`。

---

## 二、`docs/develop/` 里有什么

按「读者在什么时刻需要它」分六个位置，一份一个主题：

| 目录            | 回答                                         |
| --------------- | -------------------------------------------- |
| `quickstart/`   | 怎么跑起来、改完该跑哪些检查                 |
| `architecture/` | 系统怎么分层、每个板块怎么实现的             |
| `knowledge/`    | 知识库（规则/图/算子）上游有什么、我们差在哪 |
| `operations/`   | 怎么部署、怎么排障                           |
| `roadmap/`      | 接下来做什么、已经定了什么（决策记录）       |
| `style.md`      | 写代码要守什么规矩                           |

详见 [`develop/README.md`](develop/README.md)。

---

## 三、写在哪儿：三条铁律

1. **一个 md 只讲一个主题**，不许两份文档说同一件事。
2. **`docs/` 下任何文档不得引用 `CLAUDE.md`**——那是给 AI 看的。只允许反向。
3. **过程文件（评估报告、重构方案、复现记录）完成即删**，只把结论抽进正式文档
   —— 见 [`develop/roadmap/decisions.md`](develop/roadmap/decisions.md) D4。

---

## 四、站点内容怎么变成页面

不需要任何拷贝或同步：真源就在 `web/content/` 下、直接入库，运行期
`web/lib/content-dir.ts` 直接读盘——`web/` 是独立的 Next.js 项目，部署时只上传
它自己这一个目录，所以内容放它肚子里最稳。以前那套 `sync-content` 构建期拷贝
已随真源唯一化退役。
