# docs/ —— 文档

一个目录，两种读者，所以分开放：

| 目录                        | 给谁看                                                | 会发布到网站吗                                            |
| --------------------------- | ----------------------------------------------------- | --------------------------------------------------------- |
| [`guide/`](guide/README.md) | **用户**——怎么用本站、怎么写 Skill、怎么接 MCP        | 会：构建期拷进 `web/.generated/guide/`，对应站内 `/guide` |
| [`dev/`](dev/README.md)     | **开发者 / 运维**——怎么跑起来、怎么部署、出问题怎么查 | 不会：只留在仓库里                                        |

判断标准就一条：**这段话用户会不会在 `/guide` 上看到**。会，进 `guide/`；不会，进 `dev/`。

## `guide/` 里的东西怎么变成页面

`guide/*.mdx` 就是真源，手改即可。构建期 `web/scripts/sync-content.mjs` 把它拷进
`web/.generated/guide/`，运行期 `web/lib/guide.ts` 只读那里——`web/` 是独立的
Next.js 项目，部署时只上传它自己这一个目录，读不到仓库其余部分。
`.generated/` 不入库，每次 dev / build 现拷。
