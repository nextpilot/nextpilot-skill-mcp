## 顺手修的 bug：mutate_guards.py Windows GBK 崩溃

老大在 Windows 上跑 `mutate_guards.py` 报 `UnicodeEncodeError: 'gbk' codec can't encode character '\ufffd'`。根因：脚本把子进程守卫输出按 utf-8 + `errors="replace"` 读进来（坏字节变 U+FFFD），又原样 `print` 到 GBK 控制台 → 崩。修法：加 `_safe()`，打印前把 GBK/cp936 编不出的字符换成 `'?'`（仅用于打印，匹配的 `out` 仍用原始串）；utf-8 终端（CI/新 PowerShell）直接透传。已覆盖三处打印 `out` 的位置 + 牵连行。`py_compile`/`--list` 验证通过。
