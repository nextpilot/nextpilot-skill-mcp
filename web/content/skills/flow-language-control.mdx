## 解决什么问题

传统语音控制只能执行"起飞 / 降落"这类高层命令，无法描述精细的相对运动。Flow 提出语言引导的精细飞行范式：飞手说一句描述相对几何关系的话，无人机直接执行对应的连续控制动作。

## 核心逻辑

- 构建**原子动作库（atomic skills）**：orbit_me（环绕我）、fly_through（穿过）、follow_behind、approach 等，每个原语是参数化的闭环控制器。
- 语言模型 / 视觉模型把语音指令解析为 `{skill, 目标, 参数}`，再由视觉伺服跟踪目标，生成速度指令下发飞控。
- 语言负责"选词 + 绑定目标"，控制仍由确定性控制器完成，模型不直接输出电机量。

## 输入示例

```text
语音："环绕我飞一圈，半径 3 米"
```

## 输出示例

```json
{
  "skill": "orbit_me",
  "target": "speaker",
  "params": { "radius_m": 3, "angular_speed_rad_s": 0.5, "direction": "ccw" }
}
```

## 使用建议

- 收录本 Skill 的价值在于**范式参考**：复杂语言指令落到少量确定性控制原语，安全可验证。
- 自己实现时先只开放 3-5 个原语，每个原语有明确的速度 / 距离包络。
