## 解决什么问题

新手面对 PX4 / ArduPilot / Betaflight 几十个增益参数无从下手。本 Skill 让 LLM 基于阶跃响应日志（超调、振荡频率、上升时间）按确定性调参规则推荐下一组参数，并解释每个改动的理由。

## 核心逻辑

LLM **不凭空给数值**：先由确定性脚本从日志中算出特征量（超调量、振荡周期、阻尼比），再套预设调参规则表（如"超调 > 25% → D 增大 15% 或 P 减小 10%"）生成建议，LLM 只负责解释与排序。

## 输入示例

```json
{
  "axis": "pitch_rate",
  "current": { "P": 0.18, "I": 0.1, "D": 0.004 },
  "step_response": { "overshoot_pct": 32, "oscillation_hz": 2.8, "settle_ms": 900 }
}
```

## 输出示例

```json
{
  "next": { "P": 0.16, "I": 0.1, "D": 0.0046 },
  "reason": "超调 32% 偏大且存在 2.8Hz 振荡，先降 P 约 11%、升 D 15%；I 暂不动。",
  "safety": ["每次只试飞一个轴", "新参数首次飞行限角 15°"]
}
```

## 使用建议

- 输出必须经飞手确认后才写入参数；每次只改一个轴、一个变量。
- 调参规则表是本 Skill 的核心资产，应随机型（轴距、桨寸）积累，而非依赖模型记忆。
