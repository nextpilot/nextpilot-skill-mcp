<Zh>

NextPilot 收录飞控方向的 AI Skill 与 MCP 服务，并内置一套浏览器端运行的日志分析引擎。Skill / MCP 面向社区**免费开放**，用于交流和引流；日志分析是**平台内置能力**，不作 Skill 分发——壁垒在检查规则、阈值逻辑与故障模式知识。

下面用三步走通平台的三个入口。

</Zh>

<En>

NextPilot collects flight-control AI Skills and MCP servers, with a built-in log-analysis engine
that runs in your browser. Skills and MCP servers are **free and open** — for exchange and reach.
The log-analysis service is **built in**, not distributed as a Skill — its value is in the check
rules, thresholds, and failure-mode knowledge.

Three steps to walk through the platform's three entry points.

</En>

## 第一步：浏览 Skill 库 | Step 1 — Browse Skills

<Zh>

打开 [技能库](/skills)，你会看到一个卡片网格。每张卡片标着名称、适用平台（PX4 / ArduPilot）、依赖的 AI 模型和推荐客户端。

**先看平台维度**：一份为 ArduPilot 写的 Skill 直接套到 PX4 上，结论不一定可靠。点进卡片看详细说明，确认适用场景后再用。

找到感兴趣的 Skill 后，复制提示词或按页面说明导入到你的 AI 客户端即可使用。

</Zh>

<En>

Open the [Skills library](/skills) — a grid of cards, each with a name, platform (PX4 / ArduPilot),
required model, and recommended client.

**Read the platform first**: a Skill written for ArduPilot applied to PX4 is only as reliable as
the field semantics line up. Click into the card for details before using.

Found a Skill you like? Copy the prompt or import it into your AI client per the page instructions.

</En>

## 第二步：上传日志做分析 | Step 2 — Analyze a log

<Zh>

日志分析是平台内置能力，无需下载任何 Skill。到 [日志分析页](/analyze) 上传一份 PX4 `.ulg` 或 ArduPilot `.bin` 文件：

1. 拖入或选择 `.ulg` / `.bin` 文件
2. 解析在浏览器本地完成，不会上传原始日志
3. 结构化 findings 发送服务器生成中文报告

报告包含检查结论（严重度分 critical / warning / info）、飞行轨迹地图和关键参数曲线图。各项含义见 [数据分析实战](/guide/analyze-logs)。

</Zh>

<En>

Log analysis is built in — no Skill download needed. Go to the [analysis page](/analyze) and
upload a PX4 `.ulg` or ArduPilot `.bin`:

1. Drag or select a `.ulg` / `.bin` file
2. Parsing runs locally in your browser; raw logs are never uploaded
3. Only structured findings go to the server for the Chinese report

The report shows findings by severity (critical → warning → info), a flight-track map, and
key-parameter charts. What each means: [Data analysis guide](/guide/analyze-logs).

</En>

> <Zh>日志全程留在你的浏览器里解析，原始文件（`.ulg` / `.bin`）不会上传服务器。</Zh>
> <En>Logs are parsed entirely in your browser — the raw file (`.ulg` / `.bin`) is never uploaded.</En>

## 第三步：接入 MCP 服务 | Step 3 — Connect an MCP

<Zh>

如果你想让 AI 客户端**直接调用工具**（而不仅仅是读提示词），用 MCP 服务。从 [MCP 服务页](/mcp) 找到合适的服务，查看 `server.json` 获取接入配置。

接入方法因客户端而异——Claude、Cursor、Claude Code 的配置方式在各自 MCP 页面有说明。更多细节见 [开发一个 MCP 服务](/guide/write-mcp) 和 [接入客户端](/guide/connect-client)。

</Zh>

<En>

If you want your AI client to **call tools directly** (not just read prompts), use an MCP server.
Find one on the [MCP page](/mcp) and check its `server.json` for the connection config.

Connection method depends on the client — Claude, Cursor, and Claude Code each have their own
config; instructions are on each MCP page. More: [Build an MCP server](/guide/write-mcp) and
[Connect to your client](/guide/connect-client).

</En>
